# 퍼널별 미션 & KPI 대시보드

Next.js 14 + Tailwind CSS + @dnd-kit 기반 마케팅 퍼널 KPI & 업무 관리 대시보드

## 빠른 시작

```bash
npm install
npm run dev
```

`http://localhost:3000` 에서 확인.

## GitHub → Vercel 배포

```bash
git init
git add .
git commit -m "feat: initial dashboard"
git remote add origin https://github.com/<username>/<repo>.git
git push -u origin main
```

Vercel에서 해당 저장소를 Import → Framework: Next.js → Deploy.
